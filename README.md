## ✨ المميزات

| | |
|:--|:--|
| 💬 **نص فقط** | مفيش مايك، مفيش نطق، مفيش أي طلبات TTS — البوت بيقرأ ويكتب بس |
| 🧠 **فهم بالمعنى** | بيفهم إعادة الصياغة والمرادفات والغلط الإملائي البسيط |
| 📚 **داتا أسئلة جاهزة** | `qa_data.json` — إجابة مؤكدة لأي سؤال شبيه، حتى لو اتكتب بصياغة مختلفة |
| 🔍 **RAG من المستندات** | استرجاع تلقائي من `knowledge_docs.json` + `knowledge.js` |
| ⚡ **بث فوري** | الرد بيظهر حرف حرف (SSE) |
| 🪶 **بدون فريمورك** | Node http عادي — لا Express ولا قاعدة بيانات |

## 🏗️ المعمارية

```mermaid
flowchart LR
    U["🧑 المستخدم"] --> W["bot.html<br/>واجهة نصية"]
    W -->|"POST /api/chat"| S["server.js"]
    S --> Q["qa.js + qa_data.json<br/>مطابقة الأسئلة"]
    S --> R["knowledge.js<br/>استرجاع عربي ذكي"]
    S -->|"SSE"| G["Gemini API"]
```

**دورة الرد:** سؤال → مطابقة داتا الأسئلة (لو فيه إجابة مؤكدة نرجّعها فوراً) → استرجاع المستندات → برومبت لـ Gemini → بث النص.

## 🚀 التشغيل

```bash
# 1) المفتاح (ملف محلي — مش على Git)
echo "YOUR_KEY_HERE" > gemini_key.txt

# 2) شغّل
node server.js          # أو: start-bot.bat
```

ثم افتح 👉 **http://localhost:3456**

## 🧠 إضافة داتا أسئلة

الملف: `qa_data.json`

```json
[
  {
    "q": [
      "إزاي أتعاقد على الغاز؟",
      "عايز اشترك غاز لبيتك",
      "طريقة تسجيل مشترك جديد"
    ],
    "a": "التعاقد بيتم في أقرب مركز خدمة عملاء بالمستندات المطلوبة..."
  }
]
```

- كل سؤال في `q` هو صيغة مختلفة لنفس المعنى.
- المطابقة بتشمل مرادفات، تصريف، ترتيب كلمات مختلف، وغلط إملائي بسيط.
- التعديل على الملف بيتحمّل تلقائياً (أو `POST /api/qa/reload`).
- لو مفيش مطابقة قوية، السؤال بيروح لـ Gemini مع نفس الداتا مضافة للبرومبت.

## 📚 تحديث المعرفة العامة

## 📁 هيكل المشروع

```
├── bot.html              # الواجهة النصية
├── server.js             # سيرفر HTTP + مطابقة الأسئلة + Gemini
├── qa.js                 # محرك مطابقة الأسئلة بالمعنى
├── qa_data.json          # داتا الأسئلة والأجوبة 👈 عدّل هنا
├── knowledge.js          # قاعدة المعرفة + الاسترجاع العربي
├── knowledge_docs.json   # نصوص المستندات
├── start-bot.bat         # تشغيل بنقرة واحدة (ويندوز)
└── gemini_key.txt        # 🔑 محلي فقط — خارج Git
```
